# Hermes

An interactive helmet showcase built with HTML, CSS and JavaScript. Scroll through the video scenes. On the final colour screen, select **Pink** to switch characters. Select **HM** to restart.

[Open the live demo](https://polyakov-egor.github.io/hermes-first-screen/)

## Run locally

With Node.js installed, run `npm start` and open `http://127.0.0.1:4173/`. No dependencies or build step are required.

The site and its media live in `dist/`. GitHub Pages serves the contents of that directory from the `gh-pages` branch.
